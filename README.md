# Office
 
This was a game I was developing where every object was interactable/grabbable, and had functioning throwing physics. 

This is an older project(2021), but it still represents a longer work of mine. While the idea is something I eventually want to return to, 
it proved to be too intensive of a process to manually generate custom physics hulls/colliders for each object(there would be hundreds in the 
final version). There are tools that can automate this now (2026), so I am tempted to expand on this project again.

The idea being a game similar to the Stanley Parable playstyle, but you are in an office and you can throw and break anything you want.

Physics demo scene available on itch.io: https://justindpnt.itch.io/office-simulator
